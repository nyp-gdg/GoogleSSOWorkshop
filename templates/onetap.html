💡 How Google One Tap Works Behind the Scenes

  • Zero Redirects: Unlike standard OAuth authorization codes, Google's client SDK displays an overlay inside the current page.
  • Direct ID Token POST: Once tapped, Google signs and POSTs a verified ID Token (JWT) directly to our endpoint (/onetap/callback) with CSRF double-submit protection.
  • Backend Verification: The Flask backend verifies the token using Google's public keys via google.oauth2.id_token.verify_oauth2_token().
